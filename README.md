# OSCE Trainer

## Visão geral

Aplicação web educacional para treinamento individual de estações OSCE (Exame Clínico Objetivo Estruturado). Estudantes de medicina criam e gerenciam estações de diferentes especialidades e origens, conduzem simulações textuais com pacientes padronizados apoiados por IA e recebem avaliações formativas baseadas em checklists estruturados.

O sistema **não** é um chatbot médico, nem um sistema de gestão acadêmica, nem substitui supervisão docente, protocolos institucionais ou julgamento profissional.
